# permaura-dist

Release artifacts for [Permaura](https://permaura.com): the signed gateway binaries and desktop
installers attached to each release, and the release manifests in `manifests/` that the
installer, the npm launcher and the desktop updater read. The gateway manifest is signed, and
the desktop manifest carries a signature for each installer.

Gateway source: https://github.com/permaura/permaura
